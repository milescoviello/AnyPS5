# libwebrtc

## add Public source implementations

- [webrtc::AudioFrame::muted, data, mutable_data, UpdateFrame and data_view](../../../core/libs/prx/libwebrtc/src/AudioFrame.cpp) (libwebrtc) - the frame fields these read and write, and the samples `UpdateFrame` copies in, go through `GuestCopyIn_nid_no_patch` and `GuestCopyOut_nid_no_patch`, so a frame or sample buffer that can't be read or written throws `std::invalid_argument`, as a null frame does. This is a host-safety fallback: upstream dereferences the frame, and the console's behaviour for an inaccessible one is not measured. `UpdateFrame` still stores the fields one by one before the sample-count check, so a frame with unreadable samples keeps the new fields and its old samples. Closes when: compared with the console.
- [webrtc::AudioBuffer::CopyFrom and CopyTo](../../../core/libs/prx/libwebrtc/src/AudioBuffer.cpp) (libwebrtc) - the stream config is read with one `GuestCopyIn_nid_no_patch`. `CopyFrom` copies the `num_frames * num_channels` input samples in once before it changes the buffer, and `CopyTo` interleaves into a host array and writes it with one `GuestCopyOut_nid_no_patch`, so a config or sample buffer that can't be read or written throws `std::invalid_argument`, as a null one does, and the guest output is left untouched. This is a host-safety fallback: upstream dereferences them, and the console's behaviour for an inaccessible pointer is not measured. Closes when: compared with the console.
- [webrtc::SmoothingFilterImpl constructor, AddSample, GetAverage and SetTimeConstantMs](../../../core/libs/prx/libwebrtc/src/SmoothingFilterImpl.cpp) (libwebrtc) - each copies the 64-byte filter in with one `GuestCopyIn_nid_no_patch`, works on the copy and writes it back with one `GuestCopyOut_nid_no_patch`, so a filter that can't be read or written throws `std::invalid_argument`. This is a host-safety fallback: upstream dereferences the filter, and the console's behaviour for an inaccessible one is not measured. Closes when: compared with the console.
- [rtc::IPAddress::ipv4_address, ipv6_address, v4AddressAsHostOrderInteger and operator==, rtc::CountIPMaskBits and rtc::TruncateIP](../../../core/libs/prx/libwebrtc/src/IpAddress.cpp) (libwebrtc) - each address is copied in with one `GuestCopyIn_nid_no_patch`, and `TruncateIP` builds its result locally and writes it with one `GuestCopyOut_nid_no_patch`, so an address that can't be read, or a result that can't be written, throws `std::invalid_argument`, as a null one does. This is a host-safety fallback: upstream dereferences these pointers, and the console's behaviour for inaccessible ones is not measured. Closes when: compared with the console.
