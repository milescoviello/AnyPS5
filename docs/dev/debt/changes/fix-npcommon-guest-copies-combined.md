# libSceNpCommon

## add Unknown function info

- [Heap allocator getters](../../../core/libs/prx/libSceNpCommon/Runtime.cpp) - `sceNpHeapGetAllocator`, `sceNpMemoryHeapGetAllocator`, `sceNpMemoryHeapGetAllocatorEx`, `sceNpGlobalHeapGetAllocator` and `sceNpGlobalHeapGetAllocatorEx` build the allocator on the host and write it with one checked guest write. These functions return nothing, so for an output pointing at unmapped memory (or null) nothing is written and `errno` is left alone instead of faulting the host. The console's handling of such pointers was not measured.

## add Functional

- [sceNpUtilParseJid guest buffers](../../../core/libs/prx/libSceNpCommon/Strings.cpp) (libSceNpCommon) - the text is read once through checked copies in page-bounded chunks; the pieces, the `NpJid` and the measured length are built on the host and each written with one checked copy. An unreadable text or an unwritable output returns `NP_UTIL_ERROR_INVALID_ARGUMENT`, the null-text result, with `errno` kept; a piece that doesn't fit no longer leaves the earlier pieces in the buffer. A host-safety fallback, not measured on the console.
- [sceNpRtcFormatRFC3339 terminator](../../../core/libs/prx/libSceNpCommon/Runtime.cpp) (libSceNpCommon) - the terminator at the end of the caller's buffer is written through a checked copy; a failed write returns `0x80B50002`, the invalid-pointer result `sceRtcFormatRFC3339` gives, with `errno` kept. A host-safety fallback, not measured on the console.
- [sce::np::Time comparisons and operator+, sce::np::NpTitleId, NpTitleSecret and NpCommId](../../../core/libs/prx/libSceNpCommon/Runtime.cpp) (libSceNpCommon) - the comparison operators, `operator+`, the constructors, assignments, `Clear`, `IsEmpty`, `Equals` and `SetSecretData` copy the objects, ticks, ids and secret data they read in with `GuestCopyIn_nid_no_patch` and write their results with `GuestCopyOut_nid_no_patch`. An object or buffer that can't be read or written fails through `NotImplementedAt_nid_no_patch`, since these C++ members have no error result. `NpTitleId::Equals(const char*)` reads the text up to its first 12 characters or its terminator. This is a host-safety fallback; the console's behaviour for inaccessible objects is not measured. `ParseHex`, `BuildHex`, `Build` and `Parse(const char*, size_t)` keep their own paths.
- [sce::np::Time::SetDateTime and sceNpCalloutStopOnCtx](../../../core/libs/prx/libSceNpCommon/Runtime.cpp) (libSceNpCommon) - `SetDateTime` copies its date in with one `GuestCopyIn_nid_no_patch`, and `sceNpCalloutStopOnCtx` checks that `wasPending` is writable before it stops the callout and writes it with `GuestCopyOut_nid_no_patch`. An inaccessible date or flag returns `0x80558009`, as an unwritable `GetDateTime` result does; the time and the callout queue are left unchanged. This is a host-safety fallback: the console's result for these pointers is not measured. Closes when: compared with the console.
